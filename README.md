# 雙模式互動燈光與節拍系統 (NUCLEO-G474RE 期中專題)
宿舍練歌、節奏訓練與防打擾室友的智慧雙模式燈光節拍器。

## 1. 情境故事：誰、在哪、遇到什麼麻煩
在宿舍練吉他或唱歌時，往往無法精準抓到節拍；或者練歌太大聲，不小心吵到隔壁室友卻渾然不知。本專題旨在打造一個硬體節拍教練與即時音量視覺化警告系統，兼具自主練習節拍與防打擾室友的雙重功能。

## 2. 替身對照：故事裡的模組 → 板上替身
- 浮球電位 → **B1 藍色按鈕（PC13）**：長按 3 秒切換系統模式（Mode 0 ↔ Mode 1）。
- 音量感測器 → **Python 麥克風即時音訊採樣 (sounddevice)**：透過電腦收音並計算 RMS 振幅經由串口發送。
- 警告燈與節拍燈 → **三色 LED (PA0 紅色、PA1 黃色、PA9 綠色)** 與 **無源蜂鳴器 (PB0)**。

## 3. 功能與驗收條件：動作、預期、實測結果
- **智慧雙模式切換**：
  - *動作*：長按開發板 B1 按鈕滿 3 秒。
  - *預期*：蜂鳴器靜音並透過 LPUART1 序列埠回傳當前切換後的模式狀態。
  - *實測結果*：成功切換 Mode 0（節拍教練）與 Mode 1（Python 派對燈）。
- **Mode 0 節拍教練**：
  - *動作*：系統啟動進入 Mode 0，依據預設 120 BPM 運行。
  - *預期*：蜂鳴器每拍前 50ms 響起 880Hz 提示音，紅綠燈隨節拍瞬間最高亮度並指數漸暗。
  - *實測結果*：節拍準時、非阻塞式架構確保隨時可切換模式與接收指令。
- **Mode 1 音訊派對燈**：
  - *動作*：切換至 Mode 1 並執行 Python 上位機 (`audio_to_uart.py`)。
  - *預期*：紅燈隨聲音大小正向變亮（音量過大警示），綠燈反態漸變。
  - *實測結果*：順利將電腦麥克風音量即時映射至 STM32 的 PWM 亮度。

## 4. 用到的技術：第 3 ~ 7 週勾選表 (同投影片)
- [x] GPIO 外部中斷 (EXTI 支援按鈕長按)
- [x] TIM PWM 輸出 (TIM2 三色 LED 亮度控制、TIM3 蜂鳴器音頻)
- [x] LPUART1 非阻塞式中斷接收 (`HAL_UART_Receive_IT`)
- [x] Python 序列埠通訊 (`pyserial`) 與音訊串流處理 (`sounddevice`, `numpy`)
- [x] 非阻塞式時間差計時 (`HAL_GetTick()`)

## 5. 腳位表：用到的每支腳位與用途
- **PC13** = 板載 B1 藍色按鈕（外部中斷輸入，長按 3 秒切換 Mode）
- **PA0** = 紅色 LED (TIM2_CH1，PWM 動態亮度控制)
- **PA1** = 黃色 LED (TIM2_CH2，PWM 動態亮度控制/預留)
- **PA9** = 綠色 LED (TIM2_CH3，PWM 動態亮度控制)
- **PB0** = 無源蜂鳴器 (TIM3_CH3，PWM 音頻發聲控制)
- **PA2 / PA3** = LPUART1 (TX / RX，透過 ST-LINK USB 虛擬串口與電腦雙向通訊)

## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令
- **開發環境**：STM32CubeIDE (C 語言)、STM32CubeMX、Windows 11、Python 3.15
- **燒錄步驟**：
  1. 在 STM32CubeMX 設定對應 GPIO、TIM 與 LPUART1 參數後生成程式碼。
  2. 將 `main.c` 相關回調與邏輯填入，編譯專案 (`Ctrl + B`)。
  3. 透過 ST-LINK 將韌體燒錄至 NUCLEO-G474RE 開發板。
- **終端機設定**：鮑率 `115200`，資料位元 `8`，無校驗位 `8N1`。
- **常用指令**：
  - `bpm <數字>`：動態調整節拍速度（例如 `bpm 140`）
  - `st`：查詢並回傳當前系統狀態（BPM、Mode、Mute）
  - `mute`：一鍵開啟/關閉蜂鳴器靜音

## 7. 程式結構：哪個檔做什麼、ISR 與主迴圈分工
- **`main.c`**：
  - `main()` 主迴圈：在 Mode 0 處理非阻塞節拍與 LED 漸暗殘影；在 Mode 1 接收並更新 Python 傳入的音量 PWM 數值。
  - `HAL_UART_RxCpltCallback()` (ISR)：非阻塞式序列埠接收中斷，解析 `bpm`、`st`、`mute` 及音量數值。
  - `HAL_GPIO_EXTI_Callback()` (ISR)：處理 PC13 按鈕觸發與 3 秒長按邏輯判斷。
- **Python 端 (`audio_to_uart.py`)**：即時擷取麥克風音訊，計算 RMS 振幅並透過序列埠 (`COM3`) 每秒發送數十次數值。

## 9. AI 使用說明：哪段請 AI、你怎么查核
- **協助範圍**：AI 協助架構 STM32 非阻塞式時間差演算法 (`HAL_GetTick`)、LPUART1 中斷指令解析架構，以及 Python `sounddevice` 音訊轉 RMS 的數學對應。
- **查核方式**：透過示波器/三用電錶驗證 PWM 頻率與佔空比，並透過序列埠終端機（PuTTY）逐一測試指令回應與模式切換邏輯是否正確。

## 10. 已知限制：哪些用替身、換真貨要改哪裡
- **已知限制**：目前音量視覺化仰賴 Python 上位機透過 USB 序列埠即時傳輸，若脫離電腦獨立運作則無法進行麥克風音訊採樣。
- **換真貨改法**：若要脫離電腦獨立運作，可改用硬體麥克風模組（如 MAX9814）接至 STM32 的 ADC 腳位，透過內部 ADC 採樣取代 Python 上位機。
